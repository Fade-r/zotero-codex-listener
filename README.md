# Zotero Codex Listener

把 Zotero 的高亮、批注和论文条目下的笔记改动，直接送入指定的 Codex 会话。

## 使用

需要 Windows、Zotero、Codex 桌面端和 [Node.js 22+](https://nodejs.org/)。

1. 从 [Releases](https://github.com/Fade-r/zotero-codex-listener/releases) 下载 `.xpi`，在 Zotero 的插件管理器中选择“从文件安装插件”。
2. 打开 PDF，右键工具栏上的 **○ 监听**，设置目标会话。可粘贴 `codex://threads/…`、会话 ID 或 Markdown 会话链接。
3. 点击开始，显示 **● 监听中**；再次点击停止。无法自动找到 Node.js 时，在右键菜单中填写其路径。

每个 PDF 记住自己的目标会话，一次监听一个 PDF。重启、关闭 PDF 或连接出错后停止；每次开始都以当前内容为基准，只发送之后的变化。安装后默认停止。

## 行为

- 使用 Zotero 事件监听，连续改动合并 1.5 秒后发送；没有改动时不调用模型。
- 消息包含论文标识、原文、批注、页码和改动前后的内容。删除内容也能传递；图片注释目前仅传递位置等元信息。
- 监听期间每 10 秒检查一次本地连接，不查询论文、不唤起模型。停止后退出本地辅助进程。
- 停止会丢弃尚未发送的变化；已投递的消息可能仍在 Codex 中处理。插件不能撤回消息或取消已开始的笔记写入。
- 发送失败即停止，不自动重试，避免重复投递。恢复前请检查目标会话；重新开始不会补发停机期间的变化。

**兼容性：**当前通过 Codex 桌面端的内部本地命名管道投递，不是稳定公开 API，Codex 更新后可能需要适配。仅支持 Windows 本地会话，使用时保持一个 Codex 实例打开。插件不配置 API 密钥、不开放网络端口；投递后的内容由目标 Codex 会话按其配置处理。

首版已通过自动测试及真实 Codex 会话投递测试；Zotero 安装与工具栏操作仍待实机验收。

## 开发

无需安装 npm 依赖：

```sh
node --test
node scripts/build.mjs
```

产物在 `dist/`。`addon/` 是全部运行代码，辅助进程只提供连接检查和消息投递。
